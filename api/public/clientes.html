Clave de API

Con esta clave el sistema del cliente llama a la API (x-api-key). Solo se guarda su huella: si se pierde, hay que generar otra.

Dominios permitidos

Sitios web desde los que un navegador puede llamar a la API con la clave de este cliente (CORS). Escriba el dominio completo, sin ruta: https://portal.cardioib.com, o https://*.cardioib.com para todos sus subdominios.

Desmárquelo para que la clave solo funcione desde los dominios de la lista. El dominio de origen lo pone el navegador y un programa puede falsificarlo: esto evita que otras páginas usen la clave, pero lo que protege el acceso sigue siendo guardarla en el servidor del cliente.

Cómo verifica el sistema del cliente que el aviso viene de StartIA

Cada aviso es un POST JSON con los encabezados x-startia-evento (lote.terminado, lote.cancelado, consulta.completada, consulta.fallida o prueba), x-startia-id (único: sirve para no procesarlo dos veces), x-startia-fecha (segundos Unix) y x-startia-firma, que es v1= seguido del HMAC-SHA256 en hexadecimal de fecha + "." + cuerpo con la clave de firma. Rechace avisos de hace más de 5 minutos. Responda con un código 2xx en menos de 10 segundos; si no, se reintenta hasta 5 veces durante unos 30 minutos.

// Node.js (lea el cuerpo sin convertirlo, por ejemplo con express.raw)
const crypto = require('crypto');
const fecha = req.get('x-startia-fecha');
const esperada = 'v1=' + crypto.createHmac('sha256', CLAVE_DE_FIRMA).update(fecha + '.' + req.body).digest('hex');
const valida = esperada === req.get('x-startia-firma') && Math.abs(Date.now() / 1000 - Number(fecha)) < 300;
# Python (Flask)
import hmac, hashlib, time
fecha = request.headers['x-startia-fecha']
esperada = 'v1=' + hmac.new(CLAVE_DE_FIRMA.encode(), fecha.encode() + b'.' + request.get_data(), hashlib.sha256).hexdigest()
valida = hmac.compare_digest(esperada, request.headers['x-startia-firma']) and abs(time.time() - int(fecha)) < 300

Códigos de integración

Lo que se entrega al equipo técnico del cliente para llamar cada automatización habilitada: dirección, clave y un ejemplo listo para copiar. Si la llaman desde un navegador, su dominio debe estar en Dominios permitidos.

Credenciales por portal

Usuario y contraseña con los que el robot entra a cada portal para este cliente. Los flujos las usan como {{credenciales.usuario}} y {{credenciales.password}}, sin saber de qué cliente son. Deje un campo vacío para conservar el valor guardado.

Ningún worker ha publicado todavía su clave pública. Arranque el worker una vez (con la MASTER_KEY) y esta pantalla podrá guardar credenciales.
